# Rule UI/UX

- Terapkan prinsip mobile-first, bersih, minimal, profesional, dan berorientasi pada keterbacaan produk/harga.
- Utamakan nama, harga, satuan, kategori dan tombol WhatsApp yang jelas.
- Jangan mengarang logo, nama toko, alamat, jam, nomor telepon, daftar/harga produk nyata, atau warna merek final.
- Gunakan placeholder yang layak jika data bisnis belum dikonfirmasi.
- Implementasikan loading, error, empty catalog, no search results, dan fallback gambar sebagai state berbeda.
- Pastikan tombol memiliki label, fokus keyboard terlihat, gambar punya alt text, kontras memadai, dan target sentuh nyaman di ponsel.
- Jangan mengklaim stok real-time. Hindari animasi berat, dekorasi berlebihan, dan dependency UI besar tanpa kebutuhan.
